# Gera GRD para Unidade

Execução manual controlada da rotina semanal `ExecucaoAutomaticaServidor\GeraGRDsDocumentosComUnidade.ps1`.

O arquivo anexado foi copiado para a pasta local de execução automática e validado por SHA-256. A Central executa o modo real com `-Executar`, solicita confirmação antes de iniciar e grava os logs em `Logs\10-GeraGRDUnidade`.
