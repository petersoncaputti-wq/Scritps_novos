# Script Entrada de Documentos

Execução manual controlada de duas etapas do fluxo automático do servidor:

1. `ValidaDocumentos.ps1`, usando a cópia atualizada da pasta `ExecucaoAutomaticaServidor`.
2. `CriaPastaDisciplina.ps1`, usando a cópia da pasta `ExecucaoAutomaticaServidor`.

Os arquivos originais não são alterados. A Central solicita confirmação antes de iniciar e grava a saída em `Logs\08-EntradaDocumentos`.
